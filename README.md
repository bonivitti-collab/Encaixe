# Encaixe

PWA de agenda e confirmações para manicures, barbeiros e esteticistas.

**Live:** https://encaixe-pwa.vercel.app

## O que resolve

Profissionais de serviço vivem no WhatsApp, mas a agenda se perde no chat. O Encaixe organiza o dia e permite:

- Marcar **Confirmou / Remarcou / Cancelou** em 1 toque
- Liberar horário e **avisar a lista de espera** com mensagem pronta no Zap
- Cobrar confirmação sem digitar texto

## Stack

- Vite + React + TypeScript
- `vite-plugin-pwa` (manifest + service worker)
- Deploy na Vercel

## Dev

```bash
npm install
npm run dev
```

## Build
